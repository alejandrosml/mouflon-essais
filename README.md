# Mouflon — trials · essais

*English first, [français plus bas](#français).*

## English

This repository is where the automated trials of
[Mouflon](https://alejandrosml.github.io/Mouflon/) run. Its `essai/…` branches
hold Mouflon's source code **as it is being worked on**: each state is built
and tried on a Mac, on Windows and on Linux, then replaced by the next one.

Nothing here is a version of Mouflon, and what you find here may not work.

- **To get Mouflon**: https://alejandrosml.github.io/Mouflon/
- **The latest version and its source code**:
  [mouflon-download](https://github.com/alejandrosml/mouflon-download/releases)

Mouflon is open source, under the [MIT License](LICENSE-MIT) or the
[Apache License 2.0](LICENSE-APACHE), at your option.

Questions: asml@laposte.net.

([github.com/alejandrosml](https://github.com/alejandrosml)).
